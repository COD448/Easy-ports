# Ezport — ข้อกำหนดของระบบ / Product specification

เอกสารนี้คือสิ่งที่ระบบต้องทำ ใช้เป็นตัวตั้งเวลาปรับแก้หรือเขียนใหม่

---

## 1. แนวคิด / Concept

นักเรียนกรอกข้อมูลครั้งเดียวด้วยภาษาปกติ ระบบนำไปจัดหน้าลงเทมเพลต แล้วเลือกสี ฟอนต์
และการจัดวางให้เข้ากับ **คณะที่นักเรียนจะยื่นสมัคร** ผลลัพธ์คือแฟ้มสะสมผลงานที่พร้อมพิมพ์

หัวใจของโปรเจกต์คือ *ชุดดีไซน์ตามคณะ* — พอร์ตของคนที่ยื่นคณะวิศวกรรมศาสตร์
กับคนที่ยื่นคณะศิลปกรรมศาสตร์ ต้องไม่หน้าตาเหมือนกัน

## 2. ธีมของเว็บ / Theme

ธีมเดียวกันทั้ง 7 หน้าจอ โทนสว่าง นุ่ม ทันสมัย ปุ่มมีมิติกดแล้วยุบลง
ตกแต่งแต่ละหน้าได้อิสระ แต่ต้องสวย เรียบ และทันสมัย รองรับทั้งธีมสว่างและมืด

| Token | Light | บทบาท |
| --- | --- | --- |
| `--bg` | `#eef2f8` | พื้นหลัง |
| `--ink` | `#16203a` | ตัวอักษรหลัก |
| `--brand` | `#f2624d` | สีหลัก (ปะการัง) |
| `--mint` | `#2fbfa0` | สีรอง |
| `--sun` | `#ffc24b` | สีเน้น |

ฟอนต์: **Mitr** (หัวเรื่อง/UI) + **Sarabun** (เนื้อความ)

## 3. หน้าจอของเว็บ / Application screens

| # | หน้าจอ | เนื้อหา |

| 1 | หน้าแรก | โลโก้ Easyports ด้านบน ปุ่ม "เริ่มสร้างพอร์ต" กลางจอ |
| 2 | เลือกสไตล์ | 6 คณะ พร้อมตัวอย่างสี ฟอนต์ และลวดลายของแต่ละคณะ |

| 4 | โปรไฟล์และการศึกษา | อีเมล, เบอร์โทร, LINE, โซเชียล, พอร์ตออนไลน์, hard/soft skills, โปรแกรมที่ใช้ได้, ภาษา (พร้อมระดับ), งานอดิเรก, คติประจำใจ, แนะนำตัว, ระดับการศึกษา, GPAX, เกรดวิชาที่เกี่ยวข้อง |

| 6 | ผลงานและเกียรติบัตร | ผลงาน (ชื่อ, โจทย์, เครื่องมือ, บทบาท, รูป) และเกียรติบัตร (ชื่อ, ระดับ, วันที่, รูป) + คำนำ |
| 7 | พอร์ตโฟลิโอ | เล่มที่สร้างเสร็จ แก้ไข ดาวน์โหลด และสั่งพิมพ์ |

## 6. การแก้ไขหน้า 7 / Editing

- คลิกเพื่อเลือกองค์ประกอบ
- ลากเพื่อย้าย (เก็บตำแหน่งเป็นหน่วย `cqw` จึงไม่เพี้ยนเมื่อย่อขยายหรือสั่งพิมพ์)
- ดับเบิลคลิกเพื่อพิมพ์ทับข้อความ
- กด Delete หรือปุ่ม ✕ เพื่อลบ
- "คืนค่าหน้าเดิม" เพื่อย้อนทุกอย่างกลับ

## 7. อ้างอิงงานออกแบบ / Design references

อ้างอิงจากพอร์ตโฟลิโอนักเรียนไทย 3 เล่ม (ดนตรี / วิศวะ-วิทย์ / บริหารธุรกิจ) หลักการร่วมที่นำมาใช้:

- ทุกหน้าเป็น *หน้าที่ออกแบบมา* ไม่ใช่ข้อความไหลยาว — มีบล็อกสี หัวข้อแบบแถบ ลวดลายมุมหน้า
- ใช้ชุดสีเดียวและลวดลายประจำสาขาต่อเนื่องทั้งเล่ม
- หน้าประวัติเน้นไอคอน — ไอคอนติดต่อ ธงและแถบระดับภาษา
- หน้ากิจกรรมและผลงานเป็นตารางรูปพร้อมคำบรรยายสั้น ระบุบทบาทและสิ่งที่ได้เรียนรู้
- เกียรติบัตรเรียงเป็นตารางรูปย่อ
- หัวข้อสองภาษาไทย/อังกฤษ มีเลขหน้า และสารบัญแบบจุดไข่ปลา
